# Core Risk‑Control Compliance Metric Definitions

1. Delinquency Rate: Number of delinquent orders / Total number of orders × 100%. Only orders with delinquent days ≥ 3 days are counted.
2. Bad‑Debt Rate: Number of bad‑debt customers / Total number of customers × 100%. A bad‑debt customer is defined as a customer with at least one delinquency record of ≥30 days.
3. Transaction Frequency: Number of transactions executed by a customer within the most recent 30 days, unit: transaction count.
4. Risk Level: Classified into three tiers (Low / Medium / High Risk) based on delinquent days, transaction amount and customer qualification.
5. Compliance Violation Rate: Number of violating transactions / Total number of transactions × 100%. Violations include anti‑money‑laundering suspicious transactions, over‑limit transactions, etc.
